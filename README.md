# Pac-Man

Projeto de um jogo inspirado no clássico Pac-Man, desenvolvido utilizando HTML, CSS e JavaScript.

A aplicação foi criada como parte dos meus estudos em desenvolvimento web, com o objetivo de colocar em prática conceitos de lógica de programação, manipulação do DOM e interação com elementos da página.

## Funcionalidades

- Movimentação do personagem utilizando as setas do teclado.
- Labirinto com paredes e caminhos definidos.
- Coleta de itens e sistema de pontuação.
- Fantasmas com movimentação baseada na posição do jogador.
- Detecção de colisões.
- Sistema de vidas.
- Condições de vitória e Game Over.
- Reinício da partida.

## Tecnologias

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e elementos visuais.
- JavaScript — lógica, movimentação e mecânicas do jogo.

## Como executar

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server.
4. O jogo será aberto no navegador.

## Controles

Utilize as setas do teclado para movimentar o personagem pelo labirinto.

O objetivo é coletar os itens disponíveis, acumular pontos e evitar os fantasmas.

## Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em programação. Durante seu desenvolvimento, trabalhei com estruturas condicionais, funções, arrays, laços de repetição, manipulação do DOM e lógica de colisão.

O desenvolvimento também serviu como exercício prático para compreender melhor como HTML, CSS e JavaScript trabalham juntos em uma aplicação interativa.
